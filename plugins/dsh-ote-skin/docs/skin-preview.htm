这一版改了什么
扁了：渐变、外发光、投影只留给"浮起"和"激活"的少数地方，其余一律不上光。
描边只给该要的地方：主列头一条 1px 发丝线；其余描边都带橙色含义——+ 菜单、激活档、主按钮、头像。**橙描边一律不配辉光**：描边就是描边，发光是聚焦/运行中的语义，两者不混用。
层次拉开了：chrome 区 #121315 → 内容区 #161719 → 面板 #222427 → 控件 #303132 → 井 #0a0b0c。
标签不"仪表盘"了：mono 全大写 + 大字距的小标签改成普通 sans 小字；mono 只留给数字、路径、模型名、代码。
图标不碎了：统一 16px 一套线性图标（窗口控制钮 14px），删掉 12/13/15 混用。
输入区凹进去了：composer 与侧栏搜索框改用近黑井 #0a0b0c（规范 §2.2 新添 L0''' 一档），聚焦时上一圈橙环 + 一层外辉光；只在聚焦时亮，不平白发光。
按钮全换描边款：不再是实底。主按钮 / 发送钮 = 透明底 + 橙描边 + 橙字；次按钮 = 透明底 + 中性描边（不跟主按钮抢橙）；危险钮 = 透明底 + 红描边。所有描边都不配辉光。
这一轮逐条改的：顶栏文案 → OTE Work；logo 反色（invert(1)，黑线变白线）；头像 → 橙描边 + 橙字；列表圆点 → 品牌橙；+ 菜单与激活档 → 深底 + 橙描边（不发光）。
新写进规范的一条
§3.7 单行文字永不换行：先缩字号（最多 2 档）→ 再 ellipsis（多行块用 line-clamp）→ 截断处补 title；flex 子项必须给 min-width: 0。只有成段正文允许换行。
